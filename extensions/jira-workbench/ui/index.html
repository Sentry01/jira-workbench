    Creates one nested session in the chosen repository. The canvas makes no Jira edits; an issue session may only move its own issue to In Progress. No automatic fan-out or automatic completion.
    UPDATE JIRA

    Sync Jira statuses with the work

    Starts one Copilot session in that checks every issue in against linked sessions, pull requests, branches and commits, then moves issues whose status is wrong.

    • Status transitions only: no field edits, comments, assignments, sprint changes or new issues.
    • Done issues are never reopened. Ambiguous cases are reported, not changed.
    • The session ends with a summary table of every issue it checked.
    The session decides what to change. Review its summary in the session afterwards.
